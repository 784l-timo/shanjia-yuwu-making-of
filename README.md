# 善假于物 · 制作过程公开档案

以《劝学》“君子生非异也，善假于物也”为起点，记录一次 AI 辅助短片创作如何从文稿、
分镜和全片预演，迭代到真人口播、字幕校订与节奏调整。

![善假于物封面](assets/cover.png)

作者：田阡陌 / [784l-timo](https://github.com/784l-timo)。
本仓库包含 AI 辅助与协作内容，不代表所有文稿、代码和影像均由作者独立完成。

## 从哪里开始

1. [重启版执行简报](docs/00_重启版执行简报.md)：从先打磨局部镜头，转为先建立全片结构。
2. [整体导演计划与执行流程](docs/04_整体导演计划与执行流程_v2.md)：声音、画面和制作顺序。
3. [全片画面脚本](docs/06_全片画面脚本_v1.md)：分镜与画面设计。
4. [AI 画面与生视频任务单](docs/10_AI画面与生视频任务单_待审片确认.md)：任务拆解和生成要求。
5. [v10 整段录音识别与节奏调整](docs/30_整段录音识别与节奏调整_v10.md)：时间对齐、字幕校订及停顿修改。

## 内容

- `docs/`：按原始编号排列的 29 份规划、脚本和逐版修改记录。
- `production/`：不同阶段的 Python/JavaScript 制作脚本、镜头计划、字幕和结构化时间数据。
- `assets/`：封面与少量示例图。

原始记录中的版本号与日期予以保留。公开整理时移除了个人目录信息、录音文件名中的地理位置、
API 密钥和私人申请材料。历史文档仍可能引用未随仓库发布的大体积素材或本地临时文件。

## 已记录的关键返工

- 从“先精修渡河镜头”改为“声音和全片预演先行”。
- 人物一致性、界面可读性、画面卡顿与生成字样的逐版修正。
- 接入真人口播，使用本地 SenseVoice 识别时间点，按文稿校订字幕。
- 在实测静音区间调整停顿，保留原声与不确定识别处的记录。

v10 记录的片长约 146.16 秒，1920×1080、25fps；这是当时的阶段产物规格，
仓库没有宣称完成了人工逐字听审。

## 复用方式与复现边界

可以直接阅读制作文档、字幕和 JSON 计划，借鉴分镜、提示词、审片及返工方式。
`production/` 保存原始阶段脚本，供学习制作方法和时间轴处理逻辑使用；
脚本依赖原来的大体积影像、录音、字体、识别模型及不同阶段目录，**并非一键渲染工程**。
仓库没有包含原始真人录音、人物参考素材、完整中间视频、模型权重和最终成片。
