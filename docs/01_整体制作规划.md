# 《善假于物》整体制作规划 v1

状态：前期规划；尚未生成定妆图、动态样片或正式成片。

## 创作任务

为田阡陌创作“典耀中华·课本里的中国”语文AI作品。以《劝学》为唯一主文本，以本人原声朗诵为声音主线，以真实人物和AI视觉共同表达：借助工具扩大能力，仍需通过学习、积累和判断，把得到的答案转化为自己的理解。

用户已确认：田阡陌；不选《红烛》；认可《劝学》及“善假于物”方向；希望具有内涵和电影质感；允许当前照片作人物参考及前期占位，后期补录镜头；授权先完成整体规划。

本轮规划默认：横版16:9；约3分20秒，允许依朗诵实测调整到3—4分钟；伴随式创作，先看分镜和样片，再扩大制作。当前规划不是最终台词锁定稿，不承诺某个模型一次生成成功。

## 一、故事修订

工作片名《善假于物》，备选《渡》。主问题：“当答案来得这么容易，我还需要怎样学习？”

人物弧线：得到现成解释 → 发现自己仍然说不清楚 → 通过朗读与想象理解文本 → 主动比较、修正AI结果 → 用工具完成自己的表达。

保留“舟与江河”的核心意象，将它放在高潮。弱化数据洪水、漂浮界面和宇宙星云。自然材质的水、木、墨、纸更能让作品扎根《劝学》。大景由空间、气象、尺度和真实动作建立。

上一版需要纠正的三点：

- “思想才是方向”属于当代创作者的延伸，不应标作荀子原意的完整概括。《劝学》还强调学习对人的改变、积累、坚持与专一。
- 船不会选择人生目的属于现代比喻。删除“AI目标未设定”机械停船桥段，改为少年读水流、调整方向、实际渡河，避免暗示AI无法执行导航。
- 删除“合上电脑才成长”的结尾。电脑和课本同时留在桌上，少年修改自己的作品，表达学会使用工具。

结尾方向：“舟能载我渡河。怎样掌舵，我仍要学。”为原创暂拟，不是原文引语。若画面足以表达，可以不说出口。

## 二、声音与文本先行

先建立教材逐字核对稿，再录临时原声，再锁镜头时间。原文引用、原创旁白、屏幕文字在脚本中分栏，防止混淆。

候选文本按教材顺序取材：

1. “学不可以已”及青、冰的比喻：学习使人改变。
2. “吾尝终日而思矣……”至登高、顺风、舆马、舟楫、“善假于物”：借助外物扩展能力。
3. “不积跬步……”或“锲而不舍……”：积累与实践，为人物转变提供证据。

上述为候选范围，尚未对本地教材逐字校对；最终以本学段教材原文、正式活动要求为准。节选衔接应清楚，不能拼接成看似连续的新原文。

设计目标：原文朗诵承担主要叙事，原创话语控制在约60—100字；暂留约100—125秒原文朗诵时间，其余用于停顿、动作和环境声。实际长度以阡陌试读为准，不强行固定字速。这是内部创作目标，不是官方比例要求。

不安排AI合成角色对白。正式音轨由本人录制；前期可用字幕和节拍占位，避免把旧采访音频拼成新的话。

## 三、视觉与声音方向

现实：朴素书桌、米白上衣、课本、电脑。脸部保留真实皮肤纹理，控制屏幕反光，背景简洁。

想象：写实的中国山水和物质变化。靛蓝、纸白、木褐、晨光；墨色作为连接材料。避免满屏发光汉字、赛博霓虹和每镜头粒子特效。

每段只承担一个核心意象：染色的变化、登高的视野、渡水的工具、反复修订的积累。青与蓝避免误画成“蓝色凭空从绿叶直接流出”的科学演示，可明确使用诗性抽象画面；冰晶强调凝结纹理而非无缘由的超大冰山。

三个重点镜头：布面靛蓝化成江面；低视点经切镜到高处后显出山河；少年与舟进入开阔江面。每个重点镜头准备一条低复杂度备选方案。

运镜：固定、缓推、侧向跟随为主。真实人物近景与开阔大景交替；同场景遵守视线、运动方向、光位。16:9原生构图，不靠上下黑边制造电影感。

音乐：克制弦乐与低音纹理；环境声贯穿翻页、布料、风、水、桨。高潮只设一处，朗诵出现时让出频段与音量。先做无配乐版本检查叙事，再加入音乐。音乐来源及可用授权待实际选曲时记录。

## 五、AI生成的控制方法

先定人物参考帧、环境关键帧、镜头首尾和动作，再做短段生成。每条素材记录镜头ID、模型/版本、参考图、提示词、参数、候选号、选用区间及失败原因。

一条生成只安排一个主要动作和一种运镜。人物复杂手部、正面说话、上船连续动作优先实拍或分切，不依赖长段AI完成。清晰可读的古文由后期排字，不交给视频模型生成。

针对同一镜头最多连续试三轮：首轮验证，二轮修正明显问题，三轮仍失败就简化动作或换镜头。避免为一个复杂变形无限消耗预算。

先做6张关键帧、3类风险镜头测试；通过后才批量制作其余镜头。当前未选定视频服务，也未产生付费生成费用。后续根据可用工具和样片实测选择，不按宣传指标预先锁平台。

HyperFrames可承担预演、字幕、合成编排与渲染；电影式视频素材仍需视频生成服务或实拍提供。最终剪辑工具可依实际素材工作流调整。

## 六、质量验收

- 语文：逐字核对引用和读音；画面比喻能够指向具体原文；现代解释标为创作者理解。
- 故事：观众能指出阡陌起初的困惑、做过什么、理解发生什么变化。
- 人物：不同镜头脸型、发型、衣服一致；真人近景不被过度磨皮或无故成年化。
- 画面：曝光、色彩、视线及运动连续；舟有浮力感，桨与水接触可信；无多指和形体融化。
- 声音：本人发音清楚，音乐不盖字；停顿有意义，无忽大忽小。
- 交付：全片通看并检查文件可播放、字幕无截断、音画同步、片尾完整；按确认后的官方参数导出并复测文件体积。

暂定工作母版1920×1080、30fps，与现有采访一致。最后是否采用25或30fps统一由新增素材决定，不混剪造成节奏抖动。若约200秒并要求≤200MB，参赛版暂按总平均码率约6—7Mbps试导出，以实际文件大小与画质验收为准。

## 七、需要阡陌介入的具体内容

首先是本人表达：用自己的话讲30秒，“我用AI做过什么；有哪一次拿到了答案却没有真正理解；后来怎样弄懂”。只采用他真实说出的经历；若没有合适经历，用明确的创作情境，不能杜撰采访事实。

其后是定妆确认、原声试读、一次集中补拍、终版观看。全程不需要用户逐条复制提示词或逐镜决定技术参数。

现在可以继续：筛选多角度原始视频帧、核对教材、写双栏脚本及静态分镜。正式参赛定稿前必须解决：官方规则原文、自写旁白允许范围、本人原声、当前面貌及服装确认。
