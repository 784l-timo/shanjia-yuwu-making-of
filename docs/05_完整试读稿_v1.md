# 《善假于物》完整旁白稿 v1

用途：先锁定文案和无配音画面预演；画面确认后，再由田阡陌统一正式录音。  
建议：正式录音时正常说话，不追求“朗诵腔”；原文略慢，原创旁白更像真实思考。`〔停〕`只表示自然呼吸，不必精确计秒。

## 后期录音说明

- 只读引号内的文字，不读标题、类别和提示。
- 原文中的“生非异也”，“生”读 xìng；字幕保留“生”。
- “跂”读 qǐ，“须臾”读 xū yú，“舆马”读 yú mǎ，“跬步”读 kuǐ bù。
- 如果某句不像你平时会说的话，在录音后单独指出，不要为了迁就稿子硬读。
- 本稿按自然语速估算约 170—192 秒；无配音预演按 200 秒建立，并在段落边界保留呼吸余量。正式录音后只微调段落长度，不推翻画面结构。

## 第一段｜答案与理解｜约 0—24 秒

**类别：原创旁白**  
**语气：安静地提出自己的疑问，不要故意演困惑。**

“有时候，答案来得太快了。一个问题输入屏幕，几秒钟后，我就能得到解释。〔停〕可当我合上答案，试着用自己的话说清楚时，我还是会停下来。〔停〕答案有了，我真的懂了吗？”

## 第二段｜学习使人改变｜约 24—52 秒

**类别：教材原文**  
**语气：清楚、从容；“学不可以已”后留一点空白。**

“君子曰：学不可以已。〔停〕青，取之于蓝，而青于蓝；冰，水为之，而寒于水。”

**类别：原创旁白**  
**语气：像是在把刚读过的句子转成自己的理解。**

“学习，不只是把一句话从屏幕搬到纸上。它应该在我身上发生变化——像青出于蓝，像水凝成冰。”

## 第三段｜从思考到看见｜约 52—110 秒

**类别：教材原文**  
**语气：前半克制；读到‘登高’后逐渐打开。**

“吾尝终日而思矣，不如须臾之所学也；吾尝跂而望矣，不如登高之博见也。〔停〕登高而招，臂非加长也，而见者远；顺风而呼，声非加疾也，而闻者彰。”

**类别：原创旁白**  
**语气：自然，不要像在下定义。**

“我开始明白，借助工具，并不是让自己少想一步。〔停〕恰恰相反，它让我有机会站得更高、看得更远，也让我必须分辨：哪些只是现成的回答，哪些已经变成了我真正理解的东西。”

## 第四段｜舟楫渡河｜约 110—148 秒

**类别：教材原文**  
**语气：稳，不必为了画面壮阔而抬高音量。**

“假舆马者，非利足也，而致千里；假舟楫者，非能水也，而绝江河。〔停〕君子生非异也，善假于物也。”

**类别：原创旁白**  
**语气：画面辽阔，但人声保持真诚。**

“舟能帮我渡过江河，却不能替我选择方向。桨握在手里，我仍要观察水流，也要一次次调整。”

## 第五段｜积累与判断｜约 148—180 秒

**类别：教材原文**  
**语气：有节奏，但不喊口号。**

“积土成山，风雨兴焉；积水成渊，蛟龙生焉。〔停〕故不积跬步，无以至千里；不积小流，无以成江海。”

**类别：原创旁白**  
**语气：落回具体行动。**

“一次提问，一次比较，一次删改，看起来都很小。可真正属于我的表达，就是这样一点一点长出来的。”

## 第六段｜回到当下｜约 180—195 秒

**类别：原创旁白**  
**语气：平静、确定；最后一句后留白，不要拖长。**

“AI 可以把答案送到我面前，也可以带我看见更远的风景。〔停〕但理解、判断和修改，仍然要由我完成。〔停〕善假于物，不是停下学习，而是学会更好地出发。”
