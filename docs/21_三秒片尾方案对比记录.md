# 《善假于物》三秒片尾方案对比

日期：2026-10-16

用户在学习界面与片头预演 v2 完成后要求“继续”。本轮推进此前留待讨论的 3 秒片尾，将方向制作成可直接观看的样片，供确定最终收束方式。

## 查看入口

`shanjia-voice-preview-20261015/ending-options-20261016/index.html`

该页为单文件离线对比页，内嵌三版视频与静帧，可单独复制观看。可切换 A、B、C，连看最后 18 秒，或直接跳至 15 秒处，只看新增的 3 秒。页面附当前样片下载链接及返回 v2 完整预览的入口。

## 三种方案

| 方案 | 新增三秒内容 | 叙事取向 |
|---|---|---|
| A 留在书桌（推荐） | 延续书桌画面；右上“学不可以已”，附作品名与“田阡陌作品” | 让镜头停在学习与动笔的行动中，衔接最自然 |
| B 舟楫远行 | 江河小舟远景；作品名、最后一句的文字与创作者署名 | 用舟楫和远方完成意象收束 |
| C 呼应片头 | 重现现有独立片头海报 | 首尾信息与构图呼应，但三秒内信息较多 |

三版均为静帧，没有增加旁白、配乐、音效或动画。本轮复用现有图片，用可编辑 HTML 排版生成 A/B 尾帧；C 直接沿用现有海报，没有新增图像生成。

## 上下文与时长

每版统一取 v2 全片的 197.64—212.64 秒作为 15 秒上下文，然后接上各自 3 秒片尾，总长均为 18.00 秒。原 v2 的最后三秒预留段没有包含在上下文中，因此没有重复计算新增时长。

原 v2 全片与其预览页未修改。三个方案尚未接入完整版；当前推荐 A，最终采用方式待用户反馈。
