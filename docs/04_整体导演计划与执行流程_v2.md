# 《善假于物》整体导演计划与执行流程 v2

更新：2026-09-29。参演及创作者：田阡陌。本文为当前导演执行总纲；早期 v1 文件中的“尚未生成”“尚未选平台”等进度表述已过时，保留作过程记录。本文不是已锁定的台词稿，也不是官方参赛规则。

## 1. 导演定位：拍什么，为什么拍

以《劝学》为主文本，制作一部真人与 AI 影像结合的文学短片，暂定横版 16:9、约 3 分 20 秒。最终时长根据本人试读和正式赛事要求调整。

一句话故事：一个已经能用 AI 获得答案的少年，在阅读、想象和亲手修改的过程中，理解“善假于物”不仅是获得工具，更是通过持续学习，把工具转化为自己的能力。

中心问题：“答案有了，我真的懂了吗？”这是当代创作提问，不冒充荀子原话。片中不安排 AI 与人对立，不用“关掉电脑”象征成长；结尾课本和电脑同时留在桌上，少年继续修改自己的作品。

本片不是逐句配图的课文复原，也不是借课文包装的技术展示。原文提供结构与思想，人物行动提供变化，AI 提供现实拍摄难以获得的空间和意象。上述是我们的创作定位，不是对赛事评审偏好的已核实结论。

观众离开影片时应记得三件事：这是阡陌自己的表达；《劝学》与今天的学习仍有联系；震撼的山河最终落回一个具体的学习行动。

## 2. 全片结构与情绪曲线

| 段落       | 暂定时间      | 核心画面                  | 戏剧任务                    | 情绪      |
| -------- | --------- | --------------------- | ----------------------- | ------- |
| 答案与理解    | 0—27 秒    | 书桌、屏幕、课本、停住的笔         | 建立“得到解释却还不能自行表达”的创作情境   | 安静、有疑问  |
| 学习使人改变   | 27—61 秒   | 靛蓝布纹、水与冰、书页批注         | 让青与蓝、冰与水的比喻具有感官体验       | 好奇、进入文本 |
| 借助外物扩大能力 | 61—115 秒  | 低处受阻的视野、脚步、登高后的山河、风   | 用前后空间对比呈现能力变化           | 打开、逐渐舒展 |
| 舟楫渡河     | 115—156 秒 | 岸边人物、握桨、木舟、宽阔江面       | 全片唯一主要视觉高潮；借外物而行，人物仍在行动 | 辽阔、坚定   |
| 积累与判断    | 156—192 秒 | 桨与笔的动作匹配、比较和修改、读出自己的话 | 补足坚持与积累，避免把《劝学》缩成工具论    | 清楚、笃定   |
| 回到当下     | 192—200 秒 | 电脑与课本并置、继续写作、简洁署名     | 不再讲大道理，用行动完成结尾          | 留白、余韵   |

200 秒是制作估算，不倒逼朗诵加速。登高段只做一次视野释放，不能抢走渡河高潮。舆马、冰等意象若使全片拥挤，优先精简，不为了覆盖原文而堆景。

## 3. 人物与表演

田阡陌不是穿越古代的英雄，而是正在读书和思考的当代少年。想象空间保留米白素色上衣，避免另起古装角色造成叙事分裂。

表演依靠看、停、读、试、改五类动作，不要求夸张的困惑表情、仰天顿悟或煽情流泪。现实段保留真实肤质和日常姿态。不得将虚构的“不会解释”情境包装成对本人学习能力的纪实评价。

人物基准：用户已认可面部校准图，并于本轮确认 4 秒动态测试“像”。它是后续身份和质感参考，但不保证新角度、新动作自动一致。正面、侧面、远景仍需分别验收。旧版渡河概念图的人脸不再作为身份参考。

## 4. 电影质感的具体执行

- 构图：人物近景与环境远景交替；让前景、人物、水面、远山形成空间层次。大景承担叙事，不连续展示壁纸。
- 镜头：固定、缓推、轻侧跟为主。一条短镜头只安排一个主要动作和一种运镜。避免连续环绕、穿物、飞天和无动机变焦。
- 光线：山水段统一柔和侧逆光，固定太阳方向、天气和水色；现实段从稍冷的屏幕光转向自然、柔和的桌面光，不用浓重滤镜代替变化。
- 色彩：纸白、靛蓝、木褐、低饱和山青；人物肤色优先。自然材质比满屏粒子、霓虹和漂浮汉字更适合本片。
- 连续性：同一条舟、同一支桨、同一衣服；渡河方向以画面左向右为默认，视线、岸线和光位一致。开拍前由分镜确认，不在生成时临时改变。
- 剪辑：布纹接水纹、桨接笔、翻页声先入下个镜头。优先匹配剪辑和声音衔接，复杂变形只在确有必要时测试。
- 文字：原文字幕、界面内容、片名均后期制作，避免视频模型直接生成可读汉字。无需上下黑边伪装宽银幕。
- 真实性：手部接触、桨入水、舟的浮力是重点。复杂上船动作拆成手、船舷、远景三镜；失败时简化，不靠快切掩盖明显错误。

## 5. 声音导演

正式声音以阡陌本人朗诵为主。先录自然试读，再锁时长；不是先把镜头做满，再要求他追画面读。原文、原创旁白和屏幕文字在脚本中分栏。

原文选段兼顾学习带来的改变、借助外物、积累坚持。逐字与教材核对，节选之间保留停顿，不拼成假连续原文。“生非异也”的“生”读 xìng，字幕保留教材字形；其他读音随定稿逐项核对。

原创旁白力求少而真实，结尾“舟能载我渡河。怎样掌舵，我仍要学”仅为备选，不是荀子原话，也不一定需要说出。优先让阡陌用自己的语言表达。

先做人声加环境声的版本；如果没有音乐就看不懂，应回到脚本修改。音乐只承担情绪支撑，高潮集中在舟行大江，不从头到尾铺满。翻页、写字、布料、风、水、桨组成连续声场。已生成测试片自带音轨需单独试听和取舍，不直接当正式声音。

## 7. 最近一步：渡河样片如何落地

暂定 28 秒，只作为工作长度：

| 时间      | 画面               | 作用             |
| ------- | ---------------- | -------------- |
| 0—4 秒   | 已认可的岸边人物近景       | 人物身份与视线起点      |
| 4—9 秒   | 船舷、木纹、手握桨        | 让“工具”成为具体可触的东西 |
| 9—17 秒  | 小舟进入开阔江面，必要时分成两镜 | 全景建立空间与尺度      |
| 17—23 秒 | 桨触水、人物观察或背影      | 保留人的参与和动作因果    |
| 23—28 秒 | 回到人物／稳定的舟行画面     | 与“善假于物”句子共同收束  |

先为后三组镜头做静态构图，统一舟、衣服、光线与方向，再进入动态生成。现有 4 秒测试可剪取，但是否原样进入正式片由节奏和清晰度决定。样片朗读以试读长度重排，不照表硬塞。第一轮不追求终版音乐和复杂转场。

样片要验证的是这条视觉路线是否值得批量投入，不等于正片已经完成七分之一。

## 8. 补拍要点与分工

我负责脚本组织、分镜、提示词、资产版本管理、试验筛选、剪辑方案与质检；可用工具范围内执行制作，不承诺未经验证的自动化能力。阡陌负责自己的经历、理解、表演和原声；你负责关键审美确认、预算与终版授权。

补拍内容：书桌侧背中景；看屏幕后回看课本；停笔和改写；翻页；键盘操作；米白上衣侧脸与背影；安全地面上握木杆的手部特写。屏幕不暴露私人消息和账号信息。现实学习经历只采用本人真实提供的内容，其他标为创作情境。

手机横拍优先4K/30fps，锁曝光和白平衡，关闭美颜，每动作头尾多留2秒。无需真的下水、乘小舟或登危险高处。录音在安静软装房间分段录，每段保留自然停顿和一条备选。

## 9. 预算、返工和技术边界

已完成一条即梦 Seedance 2.5 测试：全能参考、16:9、720P、约4秒；文件检测为1280×720、60fps，含音轨。此次消耗80积分，提交后页面余额161；这是上次核验值，不代表以后实时余额。

不能按“80积分／4秒”直接推算全片费用：正片含实拍、静态与不同复杂度镜头，且平台计费可能变化。每批提交前报告镜头数、参数、页面费用及返工额度，确认后执行。不自动充值、升级会员或用完余额。

每个高风险镜头最多规划三轮尝试，但每轮仍受获批预算约束；连续失败改动作、景别或制作方式，不无限重试。优先花预算在舟行大江等真正提升表达的镜头。

工作目标母版暂定1920×1080、30fps，最终由规则和主要实拍素材确定。720P测试放进1080P时间线不会变成原生高清；终版关键镜头要评估重生成或可接受的提升清晰度方案。60fps测试转换到统一帧率时检查运动节奏，避免各段随意混用。

预演、字幕与时间线编排可由HyperFrames承担，生成影像由即梦、实拍及已有素材提供；最终工具以可验证、可修改、可交接为准。导演目标优先于工具形式。

## 10. 交付、排期与最终验收

交付目录应包含：成片母版、参赛版、字幕和朗诵稿、导演脚本与镜号清单、可复用源素材、生成参数及来源／版权记录、可编辑工程或可重建时间线说明。不仅交一个MP4。

工作量暂估：文本与试读1—2日；分镜与样片2—3日；全片预演1日；集中补拍半天；正式生成与粗剪3—5日；精剪质检1—2日。可并行，约9—15个工作日量级，受反馈、队列和返工影响，不是后台自动持续执行的承诺。赛事截止日期尚需核实，不以旧文件日期作保证。

终审三遍：第一遍只看故事，能否说清人物发生了什么变化；第二遍逐镜看脸、手、舟、水、连续性和字幕；第三遍完整听声音并检测导出参数。真人形象获认可不等于其余质量全部通过。
