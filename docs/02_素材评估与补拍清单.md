## 人物参考制作规范

优先从采访近景取清晰的正面、左右三分之二侧面及自然表情，各保留源视频时间码。避免闭眼、说话形变及动态模糊帧。原始照片仅作辅助；不混合不同年龄、发型和不同风格的人脸。

第一版临时服装采用米白素色上衣、深色长裤。它与采访素材相近，便于后补。所有生成图均按“概念帧”登记；真人实拍和生成表演分别标明，不能把生成动作写成已发生的纪录。

## 一次集中补拍

建议先做预演再拍，拍摄时带镜头编号。手机横拍即可，优先4K/30fps；设备不支持时1080P/30fps也可。固定白平衡、曝光和机位，关闭美颜，保留每个动作前后2秒。衣服在同一天保持一致。

| 镜头内容 | 取景及动作 | 用途 |
|---|---|---|
| 书桌中景 | 看屏幕，停顿，看课本；各做三遍 | 开场与结尾 |
| 面部近景 | 屏幕侧光，困惑到专注，表演克制 | 认知变化 |
| 手与键盘 | 输入、停下、修改；不必拍屏幕真实个人信息 | 真实操作 |
| 翻页与批注 | 在自己使用的《劝学》页旁笔记上圈词写字 | 文本证据 |
| 手握木杆 | 侧向软光，慢慢调整握姿 | 与舟桨镜头匹配；先保证安全和干地拍摄 |
| 全身背影 | 简洁背景，站定、向右前方走两步、停住 | 想象世界合成；不强制绿幕，有条件再用 |
| 侧身抬头 | 看低处、看远处，视线方向与分镜一致 | 登高段衔接 |
| 工作结束 | 电脑与课本并置，完成一处自己的修订 | 结尾行为证据 |
| 原声朗诵 | 安静软装房间，设备距嘴约15—25cm，避免爆破音 | 正式声音主线 |
| 环境声 | 翻页、写字、衣服动作、房间底噪各20—30秒 | 连贯声音空间 |

不必真的去河里、悬崖或高处取景。空间奇观由AI与合成承担。
