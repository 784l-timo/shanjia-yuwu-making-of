# 《善假于物》全片画面脚本 v1

版本：2026-09-30

镜头数：18 镜  
用途：无配音全片预演与后续素材生产的唯一画面表

## 预演规则

- 本轮不等待配音。画面下方显示对应旁白短句，上方小字显示镜号和时间码。
- 已有合格素材直接放入；没有素材的镜头使用构图明确的灰板，不为消灭灰板而提前生成。
- 每镜只承担一个主要动作。正式素材可以替换占位，但不随意改变镜头任务和时间位置。
- 200 秒包含呼吸余量。最终配音后，只在各段边界伸缩 1—3 秒。
- 舟楫段是唯一主要视觉高潮；登高段只做一次视野打开，不与之争抢。

## 第一版预演只检查四件事

1. 0—24 秒能否迅速建立“答案不等于理解”。
2. 52—110 秒是否过长，登高是否抢走舟楫高潮。
3. 110—156 秒是否看得懂“借助工具，同时保持人的行动”。
4. 180—200 秒是否落回真实学习，而不是口号。

人物脸部精度、终版字幕样式、配乐和正式配音均不在第一版预演的验收范围内。

## 预演通过后的素材优先级

1. 补拍镜 01—04、08、10、15—17；这些镜头低成本且决定“这是阡陌自己的作品”。
2. 整理并重剪镜 11—14 的现有舟楫素材，先解决方向与连续性。
3. 只为镜 05—07、09 的明确缺口制作新画面。
4. 最后统一录阡陌旁白，再按真实语速微调段落边界。
