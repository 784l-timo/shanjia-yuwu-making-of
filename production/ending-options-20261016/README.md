# 三秒片尾方案对比

打开 `index.html` 即可离线观看。三版共用相同的 15 秒结尾上下文，再接各自新增的 3 秒；每版总长 18 秒。

- A：留在书桌，推荐。以“学不可以已”呼应学习行动。
- B：舟楫远行。回到江河与小舟的远景。
- C：呼应片头。重现已经制作的独立片头海报。

各版 MP4 在本目录；可编辑尾帧 HTML 与 PNG 在 `assets/`。原 v2 完整版仍保留原来的书桌预留段，没有替换为其中任何方案。

三版视频完整解码、对比页切换与手机布局检查已通过，详见 `verification.json`。

重建：`node build_endings.cjs`。依赖本机 Playwright、FFmpeg、ffprobe，以及项目内 v2 全片和现有素材；不调用在线生成服务。
