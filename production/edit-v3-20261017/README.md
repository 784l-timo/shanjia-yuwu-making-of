# 《善假于物》完整片尾预演 v3

日期：2026-10-17。双击 `index.html` 可离线观看；主视频、试听音频、海报与字幕均已内嵌，可单独复制该 HTML 文件。

本版延续 v2 五处学习界面与独立片头，把新增的最后三秒替换为 A「留在书桌」：作品名、“学不可以已”、田阡陌作品。A 是推荐方案的接入审看版，最终片尾尚未锁定。

视频为 `善假于物_配音预演_v3_学习细节与完整片尾.mp4`，1920×1080、25fps，215.64 秒。可用页面按钮查看完整结尾、最后 18 秒或新增 3 秒。声音仍为 AI 试听人声，真人录音、部分真人动作与纸面新写内容仍待制作。

`build_v3.py` 只编码 75 帧新片尾，复用相邻 v2 的片头与正文片段，复制 v2 完整音频。重建依赖 v2 与片尾对比文件夹。`verification.json` 记录完整解码、前 5316 个画面包比对、全部音频包与时间戳比对、字幕及内嵌视频检查。`verify_browser.cjs` 检查离线播放、定位、媒体互斥和手机布局。

可编辑尾帧及 PNG 在 `assets/片尾_A_学不可以已.html` 与同名 PNG。片头和五处屏幕素材同样保留在 assets 中。原版、v2 和 A/B/C 对比样片均保留。
