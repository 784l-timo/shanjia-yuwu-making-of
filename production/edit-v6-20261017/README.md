## 构建与验证

1. 用本机带 NumPy 的 Python 执行 `track_screen.py`，准备边框跟踪。
2. `python3 build_v6.py --prepare` 冻结输入并准备镜头表和字幕事件。
3. `node build_and_verify.cjs` 用本机浏览器渲染动态 UI 与字幕，调用 FFmpeg 剪辑，再用本机文字识别和浏览器检查。浏览器及 Vision 需要本机访问权限。

构建复用相邻 v4 的本地剪辑函数、v5 的输入与角落遮罩；重建时需保留这些版本。完整预览页和 MP4 可独立观看。

`verification.json` 记录完整解码、时长/分辨率/帧数、音频与时间戳逐包一致、SRT 一致及内嵌视频哈希。`screen-layout-verification.json` 记录屏幕排版检查；`audit/ocr-summary.json` 记录新增开场每秒四帧的角落文字复查，66 帧中无目标候选。`browser-verification.json` 记录完整版、21.56 秒局部样片、定位、互斥和手机布局检查。`audit/check-*.png` 保留实际输出抽帧。
