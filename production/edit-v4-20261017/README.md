## 构建与检查

1. `python3 build_v4.py --prepare` 冻结输入、准备剪辑方案和字幕事件。
2. `node build_and_verify.cjs` 生成透明字幕文字层、调用本地 FFmpeg 导出并进行浏览器检查。依赖本机既有 Playwright、FFmpeg、ffprobe；浏览器启动需要本机权限。
3. `node build_and_verify.cjs --verify-only` 只检查已导出的离线页。

`verification.json` 包含完整解码、分辨率/帧率/时长、音频包与时间戳比对、字幕一致性、内嵌视频校验与结冰跳切处的背景帧差对比。`browser-verification.json` 包含播放、定位、互斥和手机检查。`audit/` 保留源素材接触表、抽帧及修改前后的检查数据。
